같은 날 중복 규칙
· 매장 방문 · 1만원 구매 · 2만원 구매는 같은 날 하나만 적립
· 오픈 기대평 스탬프와 매장 방문 스탬프도 같은 날 중복 불가
· 단, 오픈 기대평 받은 날에 1만원/2만원 구매 스탬프는 추가 적립 가능
→ 중복으로 찍으면 "같은 날짜에 이미 적립됐어요" 안내가 떠요
3. 관리자 사용법
① 고객이 매장에 왔을 때 — 스탬프 찍기
회원 명단 탭 → 이름/휴대폰으로 검색 → 방문 · 1만원↑ · 2만원↑ 중 알맞은 버튼
② 오픈 기대평 웰컴 쿠폰 지급
기대평·회원 탭 → 고객 확인 → 리워드 지급 버튼 (쿠폰+스탬프 자동)
③ 사은품 지급할 때 (쿠폰 사용 처리)
발급 쿠폰 탭 → 검색창에 쿠폰번호 입력(예: PS1552) → 사용 처리 버튼 → 사은품 전달
※ 사용 처리를 먼저 하고 사은품을 주세요. 순서가 바뀌면 같은 쿠폰이 중복 사용될 수 있어요.
고객 화면에도 사용완료로 바로 반영되며, 사용완료 쿠폰은 다시 지급하지 않습니다.
④ 잘못 처리했을 때 (취소)
· 사용 처리를 잘못했으면: 발급 쿠폰 탭 → 사용 취소 (다시 사용 가능해짐)
· 쿠폰을 잘못 발급했으면: 발급 쿠폰 탭 → 삭제 (미사용만). 웰컴 쿠폰이면 다시 받을 수 있게 복구
